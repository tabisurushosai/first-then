# プライバシーポリシー / Privacy Policy — つぎはこれ (First Then)
## 日本語
本拡張機能は個人情報を一切収集・送信しません。カード、PIN、設定などのアプリデータは chrome.storage.local 内にのみ保存されます。通常機能は外部サーバーへ自動通信せず、オフラインで動作します。利用者が「Stripeで購入」を押した場合のみ、外部の Stripe Checkout ページをブラウザで開きます。トラッキング・広告・第三者提供はありません。拡張機能を削除すると保存データも削除されます。
## English
This extension collects/transmits no personal data. App data, including cards, PIN, and settings, is stored only in chrome.storage.local. Core features make no automatic network requests and work offline. Only when the user selects "Buy with Stripe" does the extension open an external Stripe Checkout page in the browser. No tracking, ads, or sharing. Uninstalling removes all stored data.
